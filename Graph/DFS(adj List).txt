        0
       / \
      1   2
     / \
    3   4

res = [0, 1, 3, 4, 2];

Remember the three main DFS operations:
Mark the current node as visited.
Add the node to the result.
Recursively visit every unvisited neighbor.


import java.util.*;

class Solution {

    void fun(ArrayList<ArrayList<Integer>> adj,
             int node,
             ArrayList<Integer> res,
             boolean[] vis) {

        // 1. Mark current node as visited
        vis[node] = true;

        // 2. Store the current node
        res.add(node);

        // 3. Explore all neighbors
        for (int neighbor : adj.get(node)) {

            if (!vis[neighbor]) {
                fun(adj, neighbor, res, vis);
            }
        }
    }

    ArrayList<Integer> dfs(ArrayList<ArrayList<Integer>> adj) {

        int V = adj.size();

        ArrayList<Integer> res = new ArrayList<>();
        boolean[] vis = new boolean[V];

        fun(adj, 0, res, vis);

        return res;
    }
}



3. How to Build an Adjacency List

Before performing DFS, you generally need to build the graph.

A. Undirected graph

An undirected edge connects two vertices in both directions.

Suppose the edges are:

0 — 1
0 — 2
1 — 3
1 — 4

int V = 5;

ArrayList<ArrayList<Integer>> adj = new ArrayList<>();

for (int i = 0; i < V; i++) {
    adj.add(new ArrayList<>());
}

// Add undirected edges
adj.get(0).add(1);
adj.get(1).add(0);

adj.get(0).add(2);
adj.get(2).add(0);

adj.get(1).add(3);
adj.get(3).add(1);

adj.get(1).add(4);
adj.get(4).add(1);

The adjacency list is:
0 → [1, 2]
1 → [0, 3, 4]
2 → [0]
3 → [1]
4 → [1]

Key point: For an undirected graph, add both directions.
adj.get(u).add(v);
adj.get(v).add(u);

Key point: For a directed graph, add only the specified direction.
adj.get(u).add(v);

adj.get(0).add(1);
adj.get(0).add(2);
adj.get(1).add(3);

adjacency list:
0 → [1, 2]
1 → [3]
2 → []
3 → []

Weighted vs. Unweighted Graphs
Key point: DFS does not automatically use weights to decide which path is best. It simply explores neighbors. If you need shortest paths in a weighted graph, an algorithm such as Dijkstra's or Bellman–Ford may be more appropriate, depending on the weights and requirements.
